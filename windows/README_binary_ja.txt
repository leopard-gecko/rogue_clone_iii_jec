Rogue Clone III JEC 004  Windows版
===================================

Rogueは1980年頃に誕生した、文字や記号で描かれる迷宮を探索する
コンピューターRPGです。プレイヤーは怪物と戦い、さまざまな道具を
使いながら、迷宮の奥に隠された「イェンダーの魔除け」を探します。

Rogue Clone IIIは、Rogueをもとに作られたクローン系統の最終版です。
オリジナル系統のRogue 5.4と比べると、暗い部屋がなく、巻き物や水薬は
使用すると自動的に識別されるなど、仕組みがシンプルで、テンポよく
冒険を楽しめるのが特徴です。

このパッケージは、Windows 10 / 11（64ビット）向けの
Rogue Clone III JEC 004です。元のClone IIIのゲーム内容を基本的に
引き継ぎ、日本語・英語の切り替え、日本語や絵文字の入力、カラー表示、
操作オプション、現代のWindowsへの対応などを加えています。

【同梱ファイル】

  @PROGRAM@.exe             通常版
  @ORIGINAL@.exe    オリジナル設定版
  README_ja.txt           このファイル
  README_en.txt           英語のREADME
  LICENSE.txt             著作権・ライセンス

通常版とオリジナル設定版はゲーム内容が同じで、初期設定が異なります。
通常版は遊びやすさを重視した設定で、オリジナル設定版は元のClone IIIに
近い操作・表示設定を使用し、英語表示で起動します。どちらもゲーム中に
日本語と英語を切り替えることができます。

  項目　　　　　　　　　　　　　　　通常版　　　　　　　　　オリジナル設定版
  ----------------------------------------------------------------------------
  初期表示言語　　　　　　　　　　　OSの設定から選択　　　　英語
  カラー表示　　　　　　　　　　　　有効　　　　　　　　　　無効
  通路の角で自動移動　　　　　　　　有効　　　　　　　　　　無効
  連続移動中の逐次描画　　　　　　　有効　　　　　　　　　　無効
  カーソル表示　　　　　　　　　　　無効　　　　　　　　　　有効
  同一プレイヤーの複数スコア記録　　有効　　　　　　　　　　無効

カラー・移動・カーソルなどの設定は、ゲーム中のオプション画面でも
変更できます。複数スコア記録は実行ファイルのビルド時の設定です。

【起動方法】

1. ZIPファイルを任意のフォルダーに展開してください。
   セーブデータを書き込める場所を推奨します。
   （例：C:\Games\RogueCloneIII）

2. エクスプローラーから起動する場合は、通常版なら@PROGRAM@.exe、
   オリジナル設定版なら@ORIGINAL@.exeをダブルクリックします。

   既定のセーブファイルがある場合は、次のメニューが表示されます。

     [R/Enter] セーブした冒険を再開する
     [N]       新しい冒険を始める
     [F]       別のセーブファイルを選ぶ
     [Q]       終了する

   既定のセーブファイルがなければ、新しいゲームが始まります。
   [F]ではWindowsのファイル選択画面が開き、キャンセルすると
   メニューへ戻ります。新しい冒険を始めても既存のセーブファイルは
   削除されません。

3. セーブファイルを@PROGRAM@.exe（または@ORIGINAL@.exe）に
   ドラッグ＆ドロップすると、そのファイルから直接再開できます。

4. ターミナルから起動するには、展開先フォルダーを開き、
   Windows 11なら右クリックして「ターミナルで開く」を選びます。
   この項目がなければ、フォルダーのアドレスバーにpowershellと
   入力してEnterを押してください。

   通常版：
       .\@PROGRAM@.exe

   オリジナル設定版：
       .\@ORIGINAL@.exe

   コマンドプロンプト（cmd.exe）からも起動できます。
   既に開いているターミナルから引数なしで起動した場合は、
   新しいゲームが始まります。

端末は80列×24行以上でご利用ください。ゲームの描画範囲は80×24に
固定されています。ダブルクリックでの起動時には、Windows Terminalや
Console Hostのウィンドウを80×24に調整する処理が働きますが、
表示環境によっては調整できない場合があります。既に開いている
ターミナルから起動した場合は、ウィンドウサイズを変更しません。

【セーブデータとスコア】

プレイ中の保存操作でセーブファイルを作成できます。
通常版とオリジナル設定版は、次のファイルを共通で使用します。

  セーブファイル          @SAVEFILE@
  スコアファイル          @SCOREFILE@

これらは通常、起動時の作業フォルダーに作られます。エクスプローラー
から直接起動した場合は、通常、実行ファイルのあるフォルダーです。
両方の実行ファイルで同じセーブデータから再開でき、スコアも共通です。
スコア更新時はスコアファイル自体をロックするため、専用の
ロックファイルは作成しません。同じセーブファイルを複数の
ゲームから同時に操作することは避けてください。

ターミナルから既定のセーブファイルを再開するには、ファイル名を
指定します。

       .\@PROGRAM@.exe "@SAVEFILE@"

別の場所のセーブファイルを指定する場合：

       .\@PROGRAM@.exe "C:\Games\RogueCloneIII\my-save.save"

スコア一覧だけを表示する場合：

       .\@PROGRAM@.exe -s

オリジナル設定版では、実行ファイル名を@ORIGINAL@.exeに
置き換えてください。正常にゲームを再開すると、元のセーブファイルは
原則として削除される仕様です。残しておきたい場合は、再開前に
コピーしてください。

ROGUEOPTSでfile=を指定した場合は、そのセーブファイル名が優先されます。

【Windowsでの環境変数の設定】

起動時の設定には環境変数ROGUEOPTSを使用できます。
オプション項目の意味は、末尾の案内書をご覧ください。
ここではWindowsでの設定方法を説明します。

PowerShellで一時的に設定する例：

       $env:ROGUEOPTS = "name=勇者,language=ja"
       .\@PROGRAM@.exe

コマンドプロンプト（cmd.exe）での例：

       set "ROGUEOPTS=name=勇者,language=ja"
       @PROGRAM@.exe

言語を指定する場合はlanguage=ja（日本語）またはlanguage=en（英語）を
使用します。これらの設定は、その端末とそこから起動したプログラムに
有効です。エクスプローラーからのダブルクリック起動には引き継がれません。

ダブルクリック起動でも同じ設定を使う場合は、Windowsのユーザー環境
変数にROGUEOPTSを登録します。

  1. Win + Rで「ファイル名を指定して実行」を開き、sysdm.cplを実行。
  2. 「詳細設定」→「環境変数」を開く。
  3. 「ユーザー環境変数」で「新規」を選ぶ（既存なら「編集」）。
  4. 変数名にROGUEOPTS、変数値に設定文字列を入力する。
  5. 「OK」で保存する。反映されない場合はWindowsに再サインインする。

設定をやめるときは、登録したユーザー環境変数を削除してください。
